# Apply:   TV_HOST=<tv ip> tools/disable.sh examples/sony-bravia-4k-2015/debloat.txt
# Undo:    TV_HOST=<tv ip> tools/restore.sh examples/sony-bravia-4k-2015/debloat.txt com.google.android.leanbacklauncher
# Everything is DISABLED, not uninstalled. Comment out any line you want to keep.

# Android 7 has `cmd`, so build-and-install.sh uses the normal path. Note this TV's adbd is fragile:
# it drops after a burst of connections and often does not come back after a reboot until USB
# debugging is switched on again on the TV. Batch the work, do not run ADB commands in parallel.
#
# Stock launcher (device-verified): com.google.android.leanbacklauncher/.MainActivity.
# `set-home-activity` is advertised, but the observed HOME resolution still selected the stock
# launcher (priority 2) after requesting the new launcher. Do not treat command success as proof,
# and do not disable the stock launcher without a tested recovery path. A later authorized
# handover disabled only that package after disconnected-ADB recovery rehearsals; Home, settings
# and standby/wake passed. No cold reboot was tested, and this debloat list was not applied.
